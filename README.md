## Getting Started

Clone the repository and run it locally:

```bash
git clone https://github.com/Aaliya005/aaliya-portfolio.git
cd aaliya-portfolio
npm install
npm run dev
```

The app will be available at `http://localhost:5173` by default.

### Build for production

```bash
npm run build
```
